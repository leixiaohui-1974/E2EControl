**工作流程**:
```
当前状态 ──→ 场景识别 ──→ 策略选择 ──→ 参数配置 ──→ MPC求解 ──→ 控制动作
```

**使用示例**:
```python
from integration.controllers.adaptive_mpc import AdaptiveMPCController

# 创建控制器
controller = AdaptiveMPCController(
    num_pools=3,
    horizon=10,
    dt=3600.0
)

# 计算控制动作
control_actions, debug_info = controller.compute_control(
    current_levels=[3.0, 3.0, 3.0],
    current_flows=[5.0, 5.0, 5.0, 5.0],
    current_demands=[6.0, 6.0, 6.0],
    time=18,  # 傍晚
    weather={'rainfall': 15.0},
    alerts=['水位上升']
)

# 查看识别结果
print(f"场景: {debug_info['scenario']['scenario_name']}")
print(f"策略: {debug_info['mpc_config']['strategy_id']}")
print(f"风险: {debug_info['scenario']['risk_level']}")
```

| 洪峰期 | 5步 | 0.2m | 重视水位 |

**风险调整**:
- **低风险**: 正常参数，可激进优化
- **中风险**: 增加20%安全裕度
- **高风险**: 增加50%安全裕度，提高水位权重
- **紧急**: 缩短时域，最大安全裕度

## 🔬 技术细节

### 场景驱动的MPC

**流程**:
1. **状态感知**: 采集水位、流量、需求、天气、告警
2. **场景识别**: 规则+特征混合识别 → 场景类型
3. **策略查询**: 知识库检索 → 最佳策略
4. **参数配置**: 
   - 时域调整（5-15步）
   - 权重调整（根据场景优先级）
   - 约束调整（根据风险等级）
5. **风险调整**: 4级风险 → 参数微调
6. **MPC求解**: ADMM分布式优化
7. **前馈补偿**: 预测补偿（可选）
8. **动作输出**: 闸门控制信号

### 关键算法

**场景到参数的映射**:
```python
def configure_mpc(scenario, risk):
    # 基础配置
    config = get_strategy(scenario.id)
    
    # 风险调整
    if risk == 'critical':
        config.horizon = min(config.horizon, 5)
        config.safety_margin *= 1.5
    elif risk == 'high':
        config.safety_margin *= 1.2
    
    # 权重调整
    if scenario.priority == 'critical':
        config.weights.level_tracking *= 1.5
    
    return config
```

**动态更新MPC**:
```python
def update_mpc(mpc, config):
    # 更新时域
    if config.horizon != mpc.horizon:
        mpc.rebuild_problems(config.horizon)
    
    # 更新权重
    for controller in mpc.local_controllers:
        controller.weights = config.weights
    
    # 更新约束
    for controller in mpc.local_controllers:
        controller.update_constraints(config.constraints)
```
