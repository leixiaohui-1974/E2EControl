## 📋 系统概述

这是一个**高保真数字孪生仿真系统**，针对20km单一渠池进行全维度物理模拟与智能控制。系统展示了物理、信息、控制三层深度耦合的极致能力。

### 核心特性

- **🔬 高精度物理本体**: 20个空间切片，5维状态 [Z, Q, C, T_ice, n]
- **🧠 智能感知层**: 自适应参数辨识 + 网络安全防御 + 多维风险扫描
- **⚙️  鲁棒ADMM求解器**: 效率-安全冲突处理，分时电价优化
- **🎬 六重场景**: 参数漂移、经济调度、网络攻击、污染事件、边坡危机
- **📊 3x3可视化大屏**: 9个维度实时监控

## 🎬 六重场景详解

### Phase 1 (T=0-20): 参数漂移

**事件**: 中游水草疯长 (切片10-15)

**物理**: 局部粗糙度从 0.025 → 0.045

**看点**: 
- 感知层能否自适应学习新的阻力分布？
- 孪生模型能否实时校准？

### Phase 2 (T=20-40): 经济调度

**事件**: 电价进入低谷期 (0.4元/kWh)

**控制**: ADMM自动加大抽水，利用渠池库容蓄能

**看点**:
- 能耗成本如何优化？
- 避峰填谷策略是否生效？

### Phase 3 (T=40-60): 网络攻击

**事件**: 黑客篡改中游传感器 (偏差-0.5m)

**防御**: 物理一致性探针检测 → 孪生模型清洗

**看点**:
- 能否识破FDIA攻击？
- 防御模式如何启动？

### Phase 4 (T=60-80): 突发污染

**事件**: 上游排污 + 漂浮物检测

**冲突**: 加速冲污 vs. 减速防堵

**看点**:
- 多目标优先级仲裁
- 视觉跟踪漂浮物ETA

### Phase 5 (T=80-100): 边坡危机

**事件**: 暴雨后急剧退水，边坡告急

**动作**: 强制限制退水速度 (dZ/dt < 0.002 m/s)

**看点**:
- 动态约束如何压缩？
- 牺牲经济性保安全

## 🔬 关键技术

### 1. 分布式参数模拟

```python
# 空间离散 (N=20)
for i in range(N):
    # 圣维南方程
    dZ/dt = (Q_in - Q_out) / A(Z)
    Q = (A/n) * R^(2/3) * S^(1/2)  # 曼宁公式
```

### 2. 自适应参数辨识

```python
# 在线反演粗糙度
n_estimated = (A / Q) * R^(2/3) * S^(1/2)
twin_n = (1-α) * twin_n + α * n_estimated
```

### 3. 网络安全防御

```python
# 物理一致性探针
expected_dZ = dt * (Q_in - Q_out) / A
if abs(measured_dZ - expected_dZ) > threshold:
    # 检测到攻击 → 启用孪生清洗
    cleaned_Z = twin_Z_pred
```

### 4. ADMM鲁棒求解

```python
# x-update: 效率优化
min w1*||Z-Z_target||² + w2*energy_cost + w3*smoothness

# z-update: 安全投影
u_safe = project(u_opt, dynamic_constraints)
```

## 📖 技术文档

### 物理模型

- **方程**: 圣维南方程 + 对流扩散方程
- **离散**: 空间离散 (N=20)，时间步长 60s
- **边界**: 上游控制闸，下游泵站

### 感知层

- **辨识**: 最小二乘法在线估计
- **防御**: 物理一致性探针 + 残差检测
- **风险**: 边坡安全系数 + 水质指标

### 控制层

- **算法**: ADMM (交替方向乘子法)
- **目标**: 水位跟踪 + 能耗最小 + 平滑性
- **约束**: 动态约束包 (由感知层生成)
