# Phase 4.3: 自愈控制系统 (Self-Healing Control System)

## 概述

自愈控制系统是智能水网控制的关键组件，实现了故障检测、诊断、隔离、降级和恢复的完整闭环，确保系统在面对各种故障时能够自动应对，最小化人工干预。

```

## 核心模块

### 1. 故障隔离策略 (`isolation_strategy.py`)

**功能：**
- 组件注册与依赖管理
- 故障影响评估
- 隔离计划生成
- 备用组件切换
- 隔离动作执行

**组件类型：**
- 传感器 (Sensor)
- 执行器 (Actuator)
- 控制器 (Controller)

**隔离动作：**
- 停用 (DISABLE)
- 切换备用 (SWITCH_TO_BACKUP)
- 旁路 (BYPASS)
- 重新配置 (RECONFIGURE)

### 2. 降级运行模式 (`degraded_mode.py`)

**功能：**
- 系统健康度评估
- 运行模式自动选择
- 控制参数动态调整
- 功能降级管理

**运行模式：**
1. **正常模式** (NORMAL): 所有功能正常，最优控制
2. **轻度降级** (DEGRADED_MINOR): 少量组件失效，略微降低性能
3. **中度降级** (DEGRADED_MODERATE): 多个组件失效，显著降低性能，增强安全
4. **重度降级** (DEGRADED_SEVERE): 严重故障，最小功能运行，优先安全
5. **应急模式** (EMERGENCY): 紧急情况，保持最小流量，防止事故
6. **安全模式** (SAFE_MODE): 锁定关键参数，等待人工干预
7. **手动模式** (MANUAL): 完全由人工控制

**模式配置参数：**
- 控制精度 (control_precision): 0.0 ~ 1.0
- 响应时间 (response_time): 60s ~ 600s
- 安全裕度 (safety_margin): 0.5 ~ 2.5
- 最大流量变化 (max_flow_change): 0.5 ~ 10.0 m³/s
- 功能开关 (enable_optimization, enable_feedforward, enable_coordination)

### 3. 恢复管理器 (`recovery_manager.py`)

**功能：**
- 恢复计划生成
- 恢复动作执行
- 恢复进度监控
- 恢复效果验证
- 后备计划管理

**恢复策略：**
- 自动重启 (AUTO_RESTART)
- 切换备用 (SWITCH_BACKUP)
- 重新校准 (RECALIBRATE)
- 重置参数 (RESET_PARAMETERS)
- 渐进恢复 (GRADUAL_RESTORE)
- 完全恢复 (FULL_RESTORE)
- 人工干预 (MANUAL_INTERVENTION)

**恢复阶段：**
1. 空闲 (IDLE)
2. 诊断 (DIAGNOSIS)
3. 隔离 (ISOLATION)
4. 修复 (REPAIR)
5. 验证 (VALIDATION)
6. 恢复 (RESTORATION)
7. 完成 (COMPLETED)
8. 失败 (FAILED)

### 4. 自愈系统集成 (`self_healing_system.py`)

**完整工作流程：**

```
故障检测
    ↓
故障诊断与影响评估
    ↓
故障隔离 (切换备用/停用)
    ↓
运行模式降级 (调整控制参数)
    ↓
生成恢复计划
    ↓
执行恢复动作
    ↓
验证恢复效果
    ↓
恢复正常模式
    ↓
自愈完成
```

**性能指标：**
- 总故障次数
- 自动修复次数
- 需要人工干预次数
- 自愈成功率
- 平均自愈时间

python degraded_mode.py

# 测试恢复管理器
python recovery_manager.py
```

### 2. 完整系统演示

```bash
# 运行完整的自愈系统演示
python self_healing_system.py
```

### 3. 集成到现有系统

```python
from self_healing_system import SelfHealingSystem

# 创建自愈系统
healing_system = SelfHealingSystem()

# 检测到故障时调用
result = healing_system.detect_and_heal(
    fault_type="传感器漂移",
    fault_component="sensor_level_1",
    fault_severity="中",
    system_state=current_state
)

# 检查自愈结果
if result['success']:
    print(f"自愈成功，耗时 {result['healing_time']:.1f}s")
else:
    print("需要人工干预")

# 获取系统状态
status = healing_system.get_system_status()
print(f"当前模式: {status['operation_mode']}")
print(f"系统健康: {status['system_health']:.2%}")

# 生成报告
report = healing_system.generate_report()
print(report)

# 可视化历史
healing_system.visualize_healing_history()
```

## 关键特性

### 1. 多层次防御

- **预防层**：定期健康检查，预测性维护
- **检测层**：实时异常检测，快速故障识别
- **响应层**：自动隔离，快速降级
- **恢复层**：智能恢复，验证确认

### 2. 自适应降级

根据系统健康度自动选择合适的运行模式：
- 健康度 ≥ 95%: 正常模式
- 健康度 ≥ 85%: 轻度降级
- 健康度 ≥ 70%: 中度降级
- 健康度 ≥ 50%: 重度降级
- 健康度 ≥ 30%: 应急模式
- 健康度 < 30%: 安全模式

### 3. 智能恢复

- **策略选择**：根据故障类型和严重度选择最优恢复策略
- **风险评估**：评估恢复动作的风险和成功概率
- **后备计划**：低成功率时自动生成后备方案
- **渐进式恢复**：分步骤验证，确保安全

### 4. 完整记录

- 隔离历史记录
- 模式切换历史
- 恢复执行日志
- 性能统计指标

### 5. 可视化报告

生成4图表报告：
- 故障类型分布
- 自愈时间趋势
- 成功率统计
- 阶段完成情况
