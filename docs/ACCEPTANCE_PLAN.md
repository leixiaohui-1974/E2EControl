# 验收计划（正式版）

## 1. 文档目的

本文件定义 E2EControl 项目的正式验收方法，用于区分并衔接三类活动：

- 自动化测试（`pytest`、脚本回归）
- HIL/仿真验证（在环场景执行与评分）
- 人工验收（最终结论与签字）

本计划用于避免“测试通过”被误读为“验收完成”。

## 2. 适用范围

适用于仓库内以下能力域：

- 水力学与物理仿真（`hydroe2e.physics`、`hydroe2e.hydraulics`、相关场景测试）
- 控制与调度（MPC/DMPC、多池协同、调度优化）
- 数字孪生、异常检测、故障诊断、自愈链路
- API、监控、系统集成与运行流程

## 3. 当前基线（截至 2026-03-18）

当前仅将“水力学仿真模型精度”视为已进行过人工验证；其余模块均为待人工验收状态。

| 验收项 | 当前状态 | 说明 |
|---|---|---|
| 水力学仿真模型精度 | 已人工验证 | 需补齐可追溯证据（记录文件、参数、原始结果路径） |
| 控制性能（单池/多池） | 待人工验收 | 自动化与脚本结果不能替代最终验收结论 |
| 数字孪生同步 | 待人工验收 | 需建立同步精度与时延的人工判读记录 |
| 异常检测/诊断/自愈 | 待人工验收 | 需场景注入、恢复过程、人工复核闭环 |
| 调度优化/预测 | 待人工验收 | 需明确业务指标与误差容限 |
| API/系统集成 | 待人工验收 | 需覆盖稳定性、边界条件与异常流程 |

## 3.1 当前最高优先级（P0）

当前阶段的最高优先级为：**确保模型精度并完成正式可追溯验收**。

约束如下：

- 在 `ACC-PHY-001` 未达成“已通过”前，不将任何 L 级评估结果用于发布结论。
- 其他模块可继续开发与自动化验证，但人工验收排期不得高于模型精度项。
- 与模型精度相关的脚本、测试、报告路径必须进入验收记录并可复现。

执行落点：

- 精度专项说明：`docs/MODEL_ACCURACY_ACCEPTANCE.md`
- 精度验收条目：`reports/acceptance/ACC-PHY-001_20260318.md`
- 控制专项说明：`docs/CONTROL_EFFECTIVENESS_ACCEPTANCE.md`

## 4. 三类活动边界定义

### 4.1 自动化测试（开发质量门）

- 目标：快速发现回归、接口错误、基础行为偏差。
- 输出：测试日志、覆盖率、失败栈、报告文件。
- 边界：自动化通过不等于验收通过。

### 4.2 HIL/仿真验证（场景能力门）

- 目标：验证系统在多场景下的响应能力与评分表现。
- 输出：场景执行记录、评分指标、报告文件。
- 边界：HIL 结果是“候选证据”，只有进入人工验收记录并签字后才可用于正式结论。

### 4.3 人工验收（发布准入门）

- 目标：对单项能力给出最终“通过/不通过/附条件通过”结论。
- 输出：单项验收记录、验收矩阵更新、签字人与日期。
- 准入：必须引用自动化与 HIL 证据，并附原始数据位置。

## 5. 验收产物与路径规范

统一放在 `reports/acceptance/`：

- 验收矩阵：`acceptance_matrix_template.md`（按实际执行复制为版本文件）
- 单项记录：`single_item_acceptance_record_template.md`（每项复制一份）
- 建议命名：`ACC-<模块>-<编号>_<YYYYMMDD>.md`

必填信息：

- 执行环境（代码版本、依赖版本、配置文件）
- 操作步骤（可复现）
- 原始证据路径（日志、图表、报告）
- 判定标准与人工判读
- 结论、风险、责任人、签字日期

## 6. 正式验收流程

1. 立项：在验收矩阵新增条目，标记责任人与目标日期。
2. 预检：确认自动化测试和 HIL 候选证据可复现。
3. 执行：按单项模板运行并记录全过程。
4. 判读：人工依据阈值与业务规则给出结论。
5. 归档：更新验收矩阵状态并绑定记录文件路径。
6. 评审：周会复核未通过项与风险处置计划。

## 7. 状态定义

- `待验收`：未开始执行人工验收。
- `进行中`：已执行，证据收集中。
- `已通过`：人工验收完成，结论为通过。
- `附条件通过`：通过但存在明确整改项与截止日期。
- `未通过`：不满足阈值或证据不足。
- `已人工验证（待补录）`：历史结论存在但证据尚未归档。

## 8. 首批建议执行顺序

1. 水力学仿真模型精度（P0，先补证据归档，完成“已人工验证（待补录） -> 已通过”）
2. 单池控制性能（建立 `ACC-CTRL-001`）
3. 多池协同控制性能（并入 `ACC-CTRL-001` 或拆分子项）
4. 数字孪生同步精度与时延
5. 异常检测/诊断/自愈链路
6. 调度优化与预测能力
7. API 与端到端集成流程

## 9. 退出条件（阶段完成标准）

以下条件同时满足时，可判定“人工验收阶段完成”：

- 验收矩阵中所有目标条目状态为 `已通过` 或 `附条件通过`
- 每个条目均有对应单项记录文件与原始证据路径
- 未关闭风险具备责任人、整改计划与日期
