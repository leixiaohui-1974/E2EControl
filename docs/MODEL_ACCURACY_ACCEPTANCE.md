# 模型精度专项验收说明（P0）

## 1. 目的

本文件定义模型精度专项验收的最小闭环要求，用于将“历史人工验证”转化为“正式可追溯验收结论”。

本专项覆盖：

- `hydroe2e.physics` 基础物理模型精度
- `hydroe2e.hydraulics` 一维求解器精度
- 与上述模型直接相关的验证脚本和测试证据

## 2. 结论门槛

在以下条件全部满足前，`ACC-PHY-001` 不能标记为“已通过”：

- 有明确版本信息（commit、配置、依赖版本）
- 有可复现执行步骤（命令、输入、输出路径）
- 有原始证据（日志、图表、结果文件）
- 有人工判读与签字（执行、复核、审批）

## 3. 指标分层

### 3.1 必选指标（必须提供）

- 质量守恒误差（相对误差）
- 稳态解析解偏差（数值解 vs 解析解）
- 对黄金真值基准的偏差（至少包含 gauge RMSE 或等效时空误差）
- 基础响应合理性（无 NaN/Inf、无明显非物理行为）

### 3.2 可选增强指标（建议提供）

- 波速到达时间偏差
- 网格收敛趋势
- 不同求解器间一致性

## 4. 证据清单

每次补录或重验必须至少包含以下路径：

- 黄金真值基准文件路径
- 自动化测试证据路径
- 验证脚本执行日志路径
- 报告文件路径（JSON/Markdown/HTML 任一）
- 人工判读记录文件路径

建议将文件统一归档到：

- `reports/acceptance/`（验收记录）
- `reports/` 下对应实验目录（原始运行产物）
- `tests/reference_data/`（仓库内跟踪的黄金真值基准包）
